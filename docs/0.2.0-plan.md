## Frozen S1 contracts

Contracts live in `src/entities/{contracts,whole-object,representation,segmentation}.ts`. Public operation bytes are snapshotted before the first await. Validation uses Zod. Default timeout is one absolute 45-second deadline including queue time; cancellation never releases a physical slot early. Default admitted input-byte budget is 64 MiB and is reserved before copying.

Whole-object input adds `boxTolerancePx` (1–64, default 8), `maxExtentPasses` (1–3, default 3). Success contains `kind: 'whole-object'`, `seedRegion`, conservative `region`, normalized region, four half-open `bounds` intervals, completeness (`visible-object` or `boundary-limited`), method and all stage receipts. Unknowns distinguish instance ambiguity, uncertain extent, inconsistent extent and representation limits. Old failures retain their meaning.

Each extent API request asks four closed Choices: leftmost, rightmost, topmost and bottommost visible pixel of the same seeded instance. Partition each axis into at most 16 actual integer intervals plus `unknown`; recursively partition the selected interval. Never generate free coordinates. Stop within three passes when interval widths meet tolerance. If l∈[aL,bL) and r∈[aR,bR), the conservative horizontal extent is [aL,bR). Left/right intervals may coincide for a small object. Validate existence, source/ROI containment and seed intersection; do not sort, clamp or average invalid answers. Hard ROI boundaries limit visible completeness. Multiple indistinguishable seeded instances yield unknown.

`ImageRepresentationPort.prepare` receives all views for one decision request at once. Every view has source region, role and optional code-generated grid metadata. Text encoders operate on clean pixels; rendered grid labels are metadata, not extra encoded pixel views. Deduplicate identical clean/grid regions. Bound all encoded views together to 64 KiB UTF-8, each string to 64,000 UTF-16 units, and ASCII/RLE resolution to at most 64×64. Allocate resolution before encoding; never truncate a final encoded string. Record dimensions, transforms and bytes. If distinct candidate geometry collapses at that resolution, report unknown rather than fabricate precision.

`SegmentationPort.segment` receives canonical RGBA8, seed region, whole bounds, hard ROI, target/exclusions and signal. It returns a source-size binary-u8 mask plus actual backend/method/time/input dimensions or a named unknown. `settle` joins physical work; `dispose` closes only the adapter's own resources. Classifier joins its segment tasks but does not close an externally shared segmenter. Extraction crops by the mask box, zeros RGBA outside the mask, preserves source color/alpha inside it, and reports source offset. Validate binary values, dimensions, pixel cap, ROI and seed intersection. No fictitious confidence from native quality scores.

## Encoders and strict codec

Research candidates: `ascii-luma-v1`, `palette-grid-v1`, `svg-contours-v1`, `pixel-rle-v1`, `ascii-contours-v1`, `ascii-svg-layered-v1`.

RLE grammar is versioned and deterministic:

```text
PIXEL_RLE_V1
width=8 height=2
color=RGBA8 order=row-major

y0: #FF0000FF*5 #000000FF*3
y1: #FFFFFFFF*8
```

Uppercase eight-hex RGBA, positive decimal run count, no crossing rows, exact row widths, ascending unique row numbers and exact height. Validate caps before allocating; no eval, exponent/fraction counts, duplicate rows or overflow. Roundtrip equality applies to the normalized raster, not the original photo before lossy resizing. Compare raw/PNG/text bytes and tokens; do not claim RLE always compresses photographs. Prompt ablation: no grammar, grammar only, grammar plus two synthetic examples. Examples contain no benchmark ground truth.

Contour candidate: luma → p1/p99 contrast stretch → Otsu binary; independently Sobel → gradient threshold. Export BINARY and EDGES ASCII planes. Constant images must not divide by zero or invent edges. Replicate borders; distinguish transparency. Do not assume dark pixels are the target, discard small components or add morphological fitting. SVG derives from the original color raster, not thresholded pixels: at most 512 contours/2,048 vertices, no scripts, external URLs or foreignObject. Exceeding representable limits is explicit. Layered candidate sends both representations in one call, with common source geometry. Compare ASCII, SVG and layered evidence independently.

Text-only localization uses no OCR, semantic model, hidden segmentation or image input. Neural `extract` is a separate explicitly reported workflow. Text factories reject image parts before fetch; they do not silently discard them.

## Native segmentation and ownership

Port universal utilities and algorithms from the game repository without `@element` imports or game DTOs. Add optional peer `onnxruntime-node@1.23.2`; core and segmentation entry imports do not initialize native sessions. Explicit CPU required; DML only when requested and available, with no CPU fallback. Default one owned child, at most two waiting jobs. IDs fence late results; parent loss stops owned children. A job has a 10-second native limit; abort gives 250 ms grace before killing only the owned child. Capacity releases after confirmed exit/settlement; poison the adapter if exit cannot be confirmed.

## Evaluation and selection

Existing exposed images are regression/development evidence only. Acquire source-group-disjoint licensed dev40 and heldout80, with independent labels/masks. Dev: photos16 positive/4 negative, maps7/3, UI7/3. Heldout: photos30/10, maps15/5, UI15/5. Synthetic UI cannot be reported as real UI. A missing annotation is not a negative. Keep labels outside producer inputs and hash/freeze manifests before paid calls.

Primary whole-object match requires IoU≥0.5 AND visible GT coverage≥0.9 for the same GT instance. Mask IoU≥0.8. Include unknown/errors/timeouts in denominators. Photo classification is a separate closed-label request and cannot feed localization. Text control receives no image or encoding. Pin exact DeepSeek Flash/Together text and Luna Decisions/OpenAI vision control routes; unavailable routes are not auto-replaced.

All offline/security/privacy/resource/protocol gates and zero false locations on ten dev negatives are eligibility conditions. Rank eligible candidates lexicographically by photo localization, photo classification, lower p95, lower cost, then representation bytes. Freeze winner before heldout. Heldout gate: all mandatory checks, at most one false location on twenty negatives, and positive lower 95% paired-bootstrap bound versus no-image control on photo localization (10,000 resamples, fixed seed). Do not choose a runner-up on revealed holdout. If none qualifies, retain research evidence and leave public experimental release unqualified.

One dispatcher counts physical API admissions separately from receipts; failed/missing receipts retain unknown cost. Use explicit hard run budgets despite broad owner authorization. Preserve failed/incomplete runs. Never log keys, raw private media or user sessions.
