# Native segmentation provenance and smoke evidence

The MobileSAM factory uses the pinned Acly/MobileSAM revision recorded in `provenance/mobile-sam-download-receipt.json`. It checks both ONNX file lengths and SHA256 before creating sessions. Model files stay outside the package and are never downloaded by the library. The archived license and graph metadata are in `provenance/`.

The GrabCut factory accepts an explicit local OpenCV 4.13.0 `opencv.js` path. It checks the official asset's 10,964,323-byte length and SHA256 `63366510248adf3a7eddf3e793dd825404efb7df3749f4d6f8557c7fa4ca8aa0` before execution. The smoke asset was fetched from [the OpenCV 4.13.0 documentation asset](https://docs.opencv.org/4.13.0/opencv.js); its license is archived here. The asset is not committed or fetched by the adapter.

Each factory now starts an owned probe child before it resolves: MobileSAM imports ONNX Runtime there, checks the explicit provider, verifies both pinned model hashes, creates both sessions and verifies graph tensor names; GrabCut loads the exact OpenCV asset and validates the exported namespace. Probe failure is typed and the probe child is closed before the factory rejects. Both implementations run each admitted task in a child process owned by that adapter. Each pool admits one active child and up to two queued tasks. A running call remains pending through cancellation grace and child close; queued cancellation settles immediately. `settle()` and `dispose()` join only the adapter's physical work, and disposal never affects another adapter. The child receives a whole-region box prompt plus the seed region as a separate grounding constraint. Masks are returned at source dimensions, clipped to the hard ROI, and carry no inferred confidence score.

Local CPU smoke evidence (Node 24.12.0, 128×128 RGBA synthetic red rectangle on a light background, same seed and box, external pinned assets): factory probe took 0.59 seconds for MobileSAM and 0.41 seconds for GrabCut; each subsequent task still used a fresh owned child and returned a seed-grounded 1,920-pixel mask in 1.21 seconds (MobileSAM) or 0.46 seconds (GrabCut). Model/session reuse is not implemented. These are backend wiring checks only, not accuracy qualification. DML and Windows were not exercised in this worktree.

Offline focused checks: `test/native-child.test.ts` verifies cancellation grace and capacity retention against real child processes, malformed child output fencing and reuse, parent disconnect cleanup and early child exit with queued callers; `test/segmentation-extract.test.ts` covers mask values/ROI/seed validation, full-mask bounds, PNG alpha/pixel preservation, source offsets, caller-owned adapter lifetime and honest unknown results.

## Optional whole-object proposals

`createMobileSamObjectProposals` uses the same pinned encoder/decoder and an explicit CPU backend. It runs one image encoder and nine independent positive-point decoder calls, returning all four decoder masks per point in stable `C00`…`C35` order. The child packs masks immediately as `binary-lsb0`; it exits before a model sees alias-only contact sheets. Raw finite decoder quality values are diagnostics, not calibrated probabilities, and never choose a semantic object or enter a model request. The process derives boxes and seed intersection from visible foreground pixels, applies one closed Choice and a separate whole-object Noul confirmation, and unpacks only the selected mask for extraction. See the [usage and limits](../../../v02-usage.md).

The native Linux smoke for runtime `4c9c09f` passes the actual public locate/extract path and physical lifecycle checks, while the separate installed-archive consumer tests both API declarations and fixture mask extraction without ONNX. Neither test qualifies real-image accuracy; full independent end-to-end box and mask measurements remain separate.

## Paired public-photo component comparison

The [paired five-photo summary](component-comparison-summary.json) records both backends on the same independently annotated masks and supplied whole-object boxes. With deterministic reference-mask-derived seed centers, MobileSAM reaches mean per-case mask IoU 0.859 and 4/5 cases at IoU 0.8; GrabCut reaches 0.595 and 0/5. Original seeds and all failed grounding conditions remain in the report. All 53 runtime files match the current integrated runtime byte for byte. These are oracle-assisted development component results, separate from end-to-end box/selection quality. Concurrent CPU activity prevents latency ranking; neither backend is selected automatically for the caller.
