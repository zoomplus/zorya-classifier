# Object localization quality: iteration plan

This plan implements the owner's request for researched experiments and a substantial accuracy improvement. Version 0.2.0 and its evidence remain immutable. A plan or passing software checks is not an accuracy result.

## Baseline and outcome

The exposed final v0.2 study obtained 26/60 positive seed intersections but only 8/60 correct whole-object boxes: 8/30 photos, 0/15 UI, 0/15 maps. All five completed expansion attempts remained unresolved. The previous evidence gate was too weak to establish high accuracy.

The primary outcome is a mask-derived whole-object box with IoU >= 0.50 and reference coverage >= 0.90. Seed intersection is diagnostic only. A new independent 120-case cohort will contain 30 positive and 10 verified negative cases per photo/UI/map stratum. Qualification requires >=54/90 positive successes, >=12/30 in each stratum, a paired improvement >=20 percentage points over frozen v0.2, and a source-group-clustered paired 95% confidence lower bound above zero. At most one of 30 negatives may produce a false box/cutout. At least 15/30 independent source-aligned masks must reach IoU >=0.80, with missing predictions counted as zero. Freeze source diversity, annotation provenance, rights and execution policy before acquiring/opening qualification outcomes.

## Hypotheses, in order

1. **H1: preserve small objects.** Four overlapping source quadrants, one closed tile Choice, then the existing locator on one enlarged crop. Preserve global context and the source transform. No redundant global-presence gate. `none` means unresolved, not proven absence. At most four decision calls. [SAHI paper](https://arxiv.org/abs/2202.06934), [official guide](https://obss.github.io/sahi/guides/sliced-inference/). These sources test other detectors, so our expected gain remains a hypothesis.
2. **H2: segmentation prompt and selection.** Compare point-only with a fixed seed-derived box on five exposed photo cases, retaining every mask. A cell intersection does not guarantee a valid center-point prompt; native mask quality does not identify semantic objects. If a correct mask exists among candidates, test a closed semantic selection over actual masks. No oracle-derived prompt or color/game heuristic. [Segment Anything](https://github.com/facebookresearch/segment-anything), [SoM](https://arxiv.org/abs/2310.11441).
3. **H3: different proposals.** If the first probes fail, test a caller-owned text-conditioned proposal port followed by decision selection and segmentation. Investigate Grounded SAM 2 and SAM 3: source/checkpoint licenses, access, hardware, latency and memory first. No bundled weights, implicit gated-term acceptance, chosen provider, download-on-import or fallback. [Grounded SAM 2](https://github.com/IDEA-Research/Grounded-SAM-2), [SAM 3](https://github.com/facebookresearch/sam3).

## Closed screens and current pivot

- H1 overlapping zoom was rejected: positive seed intersections fell from 5/9 to 4/9, with one false seed on three negatives. [Evidence](evidence/v03/zoom-seed-screen.md).
- H2 fixed-box prompts were rejected. H2b semantic mask selection improved five exposed photo masks in isolation, but the full H2c paired pipeline remained at 1/9 correct whole-object boxes for both control and candidate. [Paired evidence](evidence/v03/semantic-segmentation-paired-screen.md).
- H3 GroundingDINO-T plus SAM2-Tiny produced a usable actual mask candidate in 5/9 positives: 3/3 photos, 0/3 UI and 2/3 maps. This is an evaluator-only upper bound. [Independent analysis](research/v03-h3-oracle-analysis.md). H3b's actual decision selection returned 3/9 correct positives, all photos, but false outputs on all three negatives: rejected. [Independent H3b evaluation](research/v03-h3b-grounded-mask-selection-evaluation.md). The subsequent [H3c plan](research/v03-h3b-failure-analysis-and-h3c-plan.md) tested identity, mask purity and completeness together; its closed result appears below. Containing the target in a large box is insufficient.
- H4a OmniParser UI proposals closely localized buttons but passed the unchanged coverage gate in 0/3 positives. [Evidence](evidence/v03/ui-proposal-box-screen.md). Follow the [alternative-mechanisms research](research/v03-next-proposals-research.md); any SAM refinement is a separately named prospective experiment.
- H4c SAM2 refinement yielded usable masks in 1/3 UI cases, insufficient for promotion. [Evidence](evidence/v03/h4c-sam2-ui-box-refinement.md). H4d SAM-HQ first exceeded GPU memory with batched decoding; sequential decoding completed but returned anomalously large masks and 0/3 usable candidates. Preserve these results and diagnose the runtime before attributing them to model quality. [Evidence](evidence/v03/h4d-samhq-ui-box-refinement.md). H4e tests fixed context padding of the input prompt while continuing to derive output boxes only from actual mask pixels.
- H4e completed with 36 valid actual masks and 3/3 usable UI candidates on the controlled screenshot. [Independent audit](research/v03-h4e-sam2-context-prompt-audit.md). H4f's conditional crop experiment is skipped: H4e already achieved 3/3 candidate availability, so the condition for running H4f was not met. Semantic selection remains unproven.
- H3c's mask-aware verifier was rejected: 0/9 final positive outputs and one false output on three negatives. In particular, it rejected a bird mask with independently measured mask IoU 0.902 and box IoU 0.954 as incomplete. Preserve the failed verifier rather than overriding its verdict during scoring. [Independent audit](research/v03-h3c-grounded-mask-selection-audit.md).
- H5 tests complementary proposal families on every image, independent top-four nominations, then a final relative mask-aware choice over at most eight nominees. It must not route by corpus labels, compare scores from different calls, or generate geometry. [Composition plan](research/v03-h5-proposal-composition-plan.md). Its native proposal phase and paid selection replay have separate timing; neither is full production latency.
- H5b is closed and rejected: union availability 8/9 → nominated availability 6/9 → correct final selections 3/9, with false outputs on all three negatives. All 32 physical receipt sets and nine output masks were independently verified; USD 0.0149639 had no unknown charges. [Audit](research/v03-h5b-paid-replay-independent-audit.md). H6 changes the evidence interface and question sequence while keeping the native masks and truth fixed: source-level presence, concise target-once questions, and context-preserving mask views. [H6 implementation plan](research/v03-h6-context-identity-plan.md).

The pilot UI source is a controlled Geany screenshot with styled button backgrounds/borders, and map cases share a Freeciv source family. These narrow development sources cannot establish natural-screen or cross-game generality. Independent qualification must retain the source-diversity and unmodified-source requirements.

## Run discipline

Record plan/profile, source/lock/input hashes, explicit route/assets, prompts, deadlines, native limits and maximum physical calls/exposure before inference. Use the existing physical-fetch recorder, unknown-charge accounting and no retries/fallbacks. Producer reads only images and authored target text: no truth, case labels, source IDs or paths in requests. DEV pilots use a fixed three-positive/one-negative draw per stratum. Retain every unknown/error/missing prediction and negative. Timings under concurrent workload are diagnostic only.

At most two complete DEV comparisons per hypothesis. A reproduced implementation defect allows a documented corrected run with a regression; a bad score does not. Pivot earlier if the cheap probe has no usable candidate masks/regions. Preserve the failed plan and cite evidence supporting the next. Never repeat prompts/seeds until an appealing result appears.

Publish raw denominators, paired gains, negatives, masks, latency, known/unknown costs and physical calls. No quality claim from fixtures, oracle-assisted probes or historical classification scores. Retain caller-configured models/providers, source-coordinate correctness, bounded resources, physical cancellation and compatible region mode.
