# Transport diagnostic: references across multiple images

Recorded before implementation/dispatch on 2026-10-21. This is a capability diagnostic alongside H6, not a new localization recipe, dataset-quality score or permission to tune the frozen H6 images/targets.

The [official OpenRouter multimodal Decisions guide](https://openrouter.ai/docs/guides/community/multimodal-decisions) and its Context7 documentation specify top-level `image_url` state parts, `detail: high` support and up to 128 images for Luna Decisions. The library already uses that shape and high detail. These contracts do not prove that a particular deployed model can bind a visual alias to the requested item across several images.

Before blaming every H5 error on mask semantics, check that basic multi-image alias selection works. Generate nine 400 × 400 synthetic cards per request. Each has a neutral visible alias R01–R09 and one large geometric object. The request asks only which labeled card contains a red triangle, with the nine aliases and `none` as closed options. Every other card contains a blue circle, except deterministic red-circle/blue-triangle distractors. No target alias, expected answer, source filename or answer position enters the request text.

Run six positive cases with the target first, middle and last in the image sequence, counterbalanced with reversed alias order, followed by two negative cases without a red triangle. Keep all eight, including errors and unknown cost. Use the existing adapter, image preparation and physical recorder, explicit Luna Decisions/OpenAI, no retries/fallbacks, eight physical calls maximum, USD 0.50 maximum, USD 0.05 unknown-cost reserve, and 45 seconds per request including preparation. Freeze generated pixels, request hashes, diagnostic source and executed SDK/recorder source before dispatch; rehash after. Select categorical maxima with existing validation and stable ties, never a universal confidence cutoff.

If all eight succeed, that rules out a basic failure on these easy alias references only; it does not prove real-object or dense-atlas understanding. If a position systematically fails, investigate payload/rendering and isolate the defect before interpreting H6 quality. Preserve the original result either way. Synthetic evidence is reported separately from the 12-case real-source pilot and never added to its accuracy denominator.
