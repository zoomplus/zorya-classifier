## Exact producer recipe

- Load the explicit local TorchScript path with `torch.jit.load(..., map_location=device).eval()`; use the already installed environment at `/root/work/zorya-classifier/.run/v03/python-env` (Python 3.12.3, Torch 2.6.0+cu124, TorchVision 0.21.0+cu124). Do not create a second environment or install packages. Wait until the H3 GPU runner has released the device before any inference.
- Decode each unique source image once as RGB and letterbox to a fixed `1280x1280` canvas, fill `(114,114,114)`, preserve aspect ratio, anchor image at `(0,0)`, and use PIL bilinear resize to `(round(width*scale), round(height*scale))`, where `scale=min(1280/width,1280/height)`. Input tensor is `[1,3,1280,1280]`, float32 RGB in `[0,1]`.
- Decode the six output tensors as `(class logits, LTRB distances)` for strides `(8,16,32)`: sigmoid the single class, decode each LTRB distance from grid-cell center in grid units, multiply by stride, concatenate all heads, retain raw score `>0.05`, then apply `torchvision.ops.nms` at IoU `0.45`. Keep no more than the first 36 post-NMS candidates in descending score order; record the pre-cap count, truncation, stable flattened head index, raw score and source-coordinate box for every retained candidate. This is one detector execution for the unique screenshot; reuse those exact boxes for its four frozen query rows. Do not rerun for each target.
- Convert boxes to source-pixel `xyxy` using the recorded top-left transform, then clamp to `[0,width]x[0,height]` and reject malformed/nonfinite/inverted boxes rather than repairing them. The official sample divides both axes by the nominal scalar scale after rounded resize dimensions; the probe must record resized dimensions and actual `scale_x=resized_width/width`, `scale_y=resized_height/height` as well as nominal scale. The geometry test will cover odd/even and portrait/landscape cases so pixel-rounding cannot silently shift boxes. Since padding is top-left anchored there are zero pad offsets; changing to centered padding is out of scope.
- Enforce a 240-second wall-clock deadline for the one unique source image, including decode, forward pass and NMS; report timeout distinctly. Persist source and model hashes, full pinned revision, package/CUDA/device versions, image and resized dimensions, transform, thresholds, raw/kept/truncated counts, candidate boxes/scores/indices, timings, and process exit status under ignored `.run/v03/ui-proposal-probe-v1/`. Store no source pixels, truth, or screenshots in committed files.

## Boundary and evaluation

This first stage is a **box-availability gate for deciding whether to spend on SAM refinement**, not a final target-success measure. It makes no provider calls and does not invoke SAM2. The target text and H3 decisions are not inputs to this class-agnostic detector. After output and receipt hashes are frozen, evaluate against existing exposed truth only through the evaluator-owned path; count a target as a potentially useful box only with IoU at least `0.50` and target coverage at least `0.90`, using the same screening criteria already declared in the parent H4a research note. This does not establish usable masks or successful localization. Report all four queries, including misses and duplicate-target outcomes. Since four target queries share one screenshot and are correlated, this screen is diagnostic only.

Only if box coverage is promising, the owner may freeze a separate second-stage plan to pass these actual boxes to the already staged caller-owned SAM2 adapter. Any mask result must be a distinct candidate and later semantic selection must use the existing caller-injected DecisionPort, with an explicit `none` option. Do not feed detector score as semantic confidence or expose truth, hidden labels, accessibility metadata, target-specific heuristics, or prompt text to candidate generation.

## Files and focused tests

- The benchmark-only CLI is `benchmarks/v03/ui-proposal-probe.py`. It accepts explicit manifest, image-root, model, license and output paths; verifies the pinned manifest/source/model/license digests; performs the pinned inference; writes a pre-inference freeze plus JSON output receipts and candidate boxes. Evidence paths are created exclusively and existing freeze/output paths are refused. A separate worker process group enforces the 240-second wall-clock timeout; on expiry the group is terminated, escalated to kill if needed, and joined before the parent writes its receipt. The producer re-hashes source, manifest, model, license and its own code after inference and records whether all remained unchanged. Boxes entirely within padding are dropped with an explicit count; malformed/nonfinite/inverted boxes fail closed.
- Focused Python geometry tests live in `test/test_v03_ui_proposal_probe.py`; they cover RGB input sizing, the fixed 1280 top-left canvas transform, round-trip box mapping under rounded resize dimensions, clipping, padding-only candidate dropping, nonfinite/inverted box rejection, candidate cap/order, exclusive historical-path protection and worker termination. They use synthetic inputs and never load the model.
- No changes to `src/`, shared public exports/contracts, package dependencies, lockfiles, defaults or model provider selection.
