## Hypothesis

H4c used SAM2 Hiera-Tiny with the same 36 frozen OmniParser boxes and passed the predeclared mask-bound availability gate for 1/3 positive UI queries. Two positives remained at IoU/coverage `0.8814496` and `0.8800505`, just below the required `0.90` target coverage. H4d asks if SAM-HQ's high-quality output token and local/global feature fusion can recover more of these thin outer button borders, without changing the source, proposals, box geometry, or prompts.

This is a controlled Geany screenshot with styled colored button borders, not a natural-UI generalization test. The only outcome sought in this first screen is same-source candidate mask availability. No provider decision or production selector is evaluated.

## Official implementation, checkpoint, and license

SysCV describes SAM-HQ as adding a high-quality output token and fusing decoder features with early/final ViT features; the hypothesis is that this boundary-oriented pathway may help with the thin outlines at issue. The [official SysCV repository](https://github.com/SysCV/sam-hq) declares Apache-2.0 and links its Transformers support. The [official SAM-HQ model card](https://huggingface.co/syscv-community/sam-hq-vit-base/raw/main/README.md) documents `SamHQModel`, `SamHQProcessor`, box prompts, original-size mask postprocessing, and `hq_token_only=True` for the HQ mask alone. The [Transformers SAM-HQ API](https://huggingface.co/docs/transformers/model_doc/sam_hq) specifies that `hq_token_only=True` uses only the HQ token mask path; `multimask_output=False` requests one mask. These controls will be fixed as `hq_token_only=True, multimask_output=False` before inference; no output score will be used to rank candidates.

The producer must not read evaluator labels, case target names, query text, or truth files.
- Create one image encoding per source, then pass the same batch of 36 original source-coordinate XYXY boxes to the model, in order. Use fp16 weights/activations, `multimask_output=False`, and `hq_token_only=True`; use the processor's own source-size restoration. Do not expand boxes, add points or negative cues, crop to prompt boxes, apply masks/thresholds selected from truth, change candidate order, or choose a candidate using model quality scores.
- Convert each returned sole HQ-token logit mask with the fixed zero threshold to a binary full-source mask. Retain all 36 masks, including empty masks; derive pixel area and exclusive-max source bounds from the actual binary pixels. Preserve the original proposal ordinal, H4a flattened index, raw detector score, and original box as the identity mapping. Do not use or serialize model quality scores for selection.
- Enforce one fixed 240-second wall deadline in a separately owned process group. On timeout or error terminate/kill and join the worker before writing a terminal run receipt. Run offline with auto-download disabled.
- Freeze source/H4a/asset/script hashes and the complete prompt/output recipe exclusively before model load. Rehash those inputs and script after inference. Refuse existing output paths. Store outputs in ignored `.run/v03/h4d-samhq-ui-box-refinement-v1/`; no pixels or labels are committed.
