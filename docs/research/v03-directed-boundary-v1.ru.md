# v0.3 directed-boundary v1 (направленные лучи по границам цвета HSV12)

Отдельный именованный локальный эксперимент v0.3: поверх **неизменённых** связных компонент карты **HSV12** из прогона `color-normalization-hsv12-v1` детектор линий (OpenCV LSD) строит snapped-сегменты; от концов сегментов выпускаются **направленные лучи** вдоль исходного направления LSD до **первого** перехода метки исходной HSV12-карты; при достаточной дистанции луч становится **барьером** и **разрезает** родительскую компоненту на фрагменты (геометрическое разбиение, без правки пикселей). Это не штатное поведение библиотеки, не выбор цели и не автоматическое распознавание.
