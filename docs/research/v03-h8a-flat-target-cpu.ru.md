# Гипотеза: плоский текст для H8a CPU

**Статус:** проверяемая гипотеза для отдельного исследовательского рецепта; это не результат проверки качества и не основание менять исторический профиль.

## Изолированная техническая проверка

На проблемном ориентированном кадре Thunar 1280×1024 явный v2 прошёл CPU worker smoke: запрос и ответ подтвердили `h8a-cpu-flat-target-v2`; получены 7 масок D и 36 масок U, все 43 маски проверены по SHA-256, общий размер упакованных масок — 7 045 120 байт. Прогон занял 19,048 секунды и не сделал provider fetch. Результат сохранён в `main-live-dev40-v1/technical-diagnosis-dev8-v1/real-cpu-flat-v2-smoke-integrated-v1/main-result.json` вне репозитория; SHA-256: `2b066f34da81c9fa7135c1031ab614cb7500490a994e0baaa898a2e3ceed66a2`. Закреплённые исходные байты до и после прогона совпали.

Офлайн-проверка текстовой формы для `transformers` 4.57.3 приняла 40/40 плоских входов вместо 38/40 вложенных; у 38 ранее принятых подписей входные тензоры токенизатора совпали. Историческая строка DEV8 остаётся остановленной и неизменной: этот технический smoke не повторял кампанию, не измерял точность и не подтверждает качество локализации. Независимая квалификация и MCP остаются невыполненными.

В изолированной диагностике DEV8 с закреплённым `transformers` 4.57.3 вложенная форма текста процессора GroundingDINO принята для 38 из 40 входов. Два входа завершаются ошибкой `TextEncodeInput must be Union[TextInputSequence, Tuple[InputSequence, InputSequence]]`. Передача тех же подписей одной объединённой строкой принята для всех 40; у 38 ранее работавших подписей идентичны входы текстового токенизатора и поля attention/token type. Диагностика не запускала детектор, модельные запросы или кампанию качества.

**Гипотеза:** для ранее принятых подписей плоское текстовое представление позволит тому же процессору, токенизатору и детектору дойти до штатной обработки, сохранив те же тензоры текста. Оно также устранит наблюдаемую ошибку формы для двух конкретных подписей. Это не предсказывает точность локализации и не доказывает улучшение качества.

**Ограничение эксперимента:** изменение доступно только через явно выбранный кандидат `h8a-cpu-flat-target-v2`; цель детекции и исходная строка запроса остаются прежними. Исторический v1 сохраняет форму входа, значения по умолчанию и идентичности. Запись неудачного реального v1-прогона остаётся неизменной; v2 не подставляется в v1 и не использует его кэш.

**Следующая проверка:** обычные изолированные тесты подтверждают выбор и идентичность рецепта, отказ при несовпадении идентификаторов и сохранение поведения v1. Отдельный владелец может затем выполнить ограниченный CPU smoke через явный v2 native port. Никакого повторного DEV/QUAL или вывода о качестве эта проверка сама по себе не разрешает.
