# v0.3 contour-completion v1 (завершение внешнего контура)

Отдельный именованный локальный эксперимент v0.3: поверх **неизменённых** связных компонент карты **HSV12** из прогона `color-normalization-hsv12-v1` строятся две геометрические вариации маски в **исходных** координатах пикселей. Это не штатное поведение библиотеки и не автоматическое распознавание.

## Статус

**Статус:** `scoped-verified-offline-dev` — один полный локальный прогон построителя и оценщика на зафиксированной когорте, независимый аудит артефактов пройден, **измеренные метрики** и авторизованные визуализации/отчёт сгенерированы из существующих квитанций (без повторного прогона построителя/оценщика).

**Провайдер / платные вызовы:** **0**.

**Локальные проверки репозитория:** выполняет main после handoff; здесь **не заявляется** их результат (**ожидает main**).

## Гипотеза и варианты масок

Соседние фрагменты одной HSV12-компоненты иногда можно **соединить крайние точки компоненты прямыми отрезками, образовав выпуклую оболочку**, не меняя исходную рамку кандидата и не сливая идентификаторы компонент. Цена — заполнение реальных вогнутостей и **добавление фона** внутри оболочки; оболочка **никогда не выходит за исходную рамку компоненты**.

| Вариант            | Определение                                                                                                                 |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| **исходная маска** | маска компоненты (как в v1 на карте компонент HSV12)                                                                        |
| **A**              | растр выпуклой оболочки **минус** только **закрытые** фоновые «дыры» исходной маски (8-соседнее заливание от границы кропа) |
| **B**              | полный растр выпуклой оболочки (включая заполнение закрытых дыр)                                                            |

Подстройка параметров **после** исхода запрещена.

## Как опыт соотносится с возможностями библиотеки

| Возможность                             | Статус           | Связь с этим экспериментом                                                                  |
| --------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------- |
| `classify` + явный `DecisionPort`       | Поддерживается   | Закрытый идентификатор класса; **нет** гарантии точности; эксперимент **не** классифицирует |
| `locate` (по умолчанию)                 | Экспериментально | Грубая область-кандидат, не доказательство целого объекта                                   |
| `locate({ mode: 'whole-object' })`      | Экспериментально | Не проходил отдельную квалификацию качества                                                 |
| `extract` / `SegmenterPort` вызывающего | Экспериментально | Рамка, центр и маска из пикселей + проверка; **не** меняется здесь                          |
| `objectProposals`                       | Экспериментально | На стороне вызывающего; **не** меняется                                                     |
| `experimental-text`                     | Отклонён         | Квалификация ожидает отдельного прогона                                                     |

Эксперимент меняет **только геометрию маски-кандидата** для локального сравнения вырезок на зафиксированных картах HSV12; **не** выбирает цель, **не** оценивает присутствие, **не** меняет публичный интерфейс и поведение по умолчанию.
