**Status: closed and rejected (2026-10-21).** The bounded corrected live run completed independent evaluation and **failed** the predeclared gate: **2/9** positive same-mask retained versus the frozen H8a baseline **7/9**, with **0/3** negative false outputs. See [results](v03-h9-target-blind-mask-identity-results.md) and [sanitized independent evaluation](../evidence/v03/h9-target-blind-mask-identity-independent-evaluation.json). A prior stopped run preserved a schema-only HTTP 400 on stage two; that technical failure is separate from this semantic gate outcome. **Do not tune prompts, schemas, or thresholds against these same twelve cases** to recover a pass; stop this continuation line. No production promotion or release recommendation.

The plan text below remains as originally accepted for audit traceability. H8a Luna is the baseline because it achieved the same 7/9 positive same-mask result and the same two false outputs as H8b Sol, at much lower observed cost. H8a stays immutable; H9 is a separately named recipe with separately frozen prompts and budget.

## Hypothesis

H6 and both H8 arms already ask target-aware presence, nominee and final-selection questions with closed `none` options. H8a nevertheless marked the negative photo and UI examples present and returned masks for them. Repeating a target-aware presence or `none` question would not test a new mechanism. H9 instead separates visual description from target comparison: first describe the pixels of the selected mask without seeing the requested target or any prior decision, then compare that description with the original target and its relation. The hypothesis is that the first request will produce less target-conditioned evidence and the second can reject a semantically mismatched selected candidate. It is a diagnostic hypothesis, not an assumed benefit.

Prior work motivates testing hallucination and candidate identity directly. POPE reports object hallucinations associated with language instructions and co-occurring objects, and evaluates existence claims with explicit negative probes; that supports retaining hard negatives, not a claim that a two-stage verifier will fix them ([Li et al., 2023](https://arxiv.org/abs/2305.10355)). Counterfactual Segmentation Reasoning documents masks for wrong or absent objects as pixel-grounding hallucinations, supporting an explicit selected-mask identity check ([Li et al., 2025](https://arxiv.org/abs/2506.21546)). Geigle et al. found that grounding objectives alone had little to no effect on open-caption object hallucination, so adding a grounding-flavored step is not itself evidence of improvement ([Geigle et al., 2024](https://arxiv.org/abs/2406.14492)). Research on intrinsic self-correction also finds prompt fairness and zero temperature matter; H9 should therefore be treated as a new evidence-separation experiment rather than an assumption that asking the same model to reconsider its earlier answer will help ([Liu et al., 2024](https://arxiv.org/abs/2406.15673)).

## Frozen inputs and stages

Use the exact 12 H8a cases, original target text, H8a-selected actual masks, and H8a Luna route: `openai/gpt-6-luna`, OpenAI chat completions, JSON Schema, medium reasoning, 4096 output tokens, no fallback. The H8a run SHA-256 is `1def8b64894f520e6e3ddd9c432212e1333684ae5db1e7c5747485c185cbb98a`; its freeze SHA-256 is `d371f64a76effb8b96951709c03a4801e1751f8f8032d363623ba1903b33ed27`. Freeze the H8a selected-mask paths, bytes, hashes, source dimensions, and candidate provenance before H9; send the exact source image and exact actual mask pixels as captured, without editing or regenerating masks.

For each case with an H8a selected mask, run at most these two stages:

1. **Target-blind facts.** Send the unmodified full image, a candidate-mask view derived from the exact selected mask, and a short fixed instruction to describe only visible facts about the highlighted region and its immediate context. Do not send the target, target description, relation wording, stratum, truth, case/source identifiers, prior choices, candidate scores, or other model outputs. Return a fixed structured record of visible category, directly observable appearance, spatial/context relation, and explicit evidence; do not return a match decision, confidence score, coordinates, or inferred hidden geometry.
2. **Closed target comparison.** Send the original authored target and relation plus only the target-blind factual record. Do not send prior H8 choices or request a new mask. Return exactly `match`, `mismatch`, or `insufficient-evidence`, with a short evidence reference to the factual fields. `match` requires explicit support in the facts for the requested identity and relation; a broad category or contextual plausibility alone is insufficient. `mismatch` and `insufficient-evidence` both abstain. Preserve the H8a mask byte-for-byte only after `match`; otherwise return unknown and retain the reason.

For a case where H8a produced no selected mask, issue no H9 request and preserve that no-output result. Count it as a failed positive and an abstained negative in the fixed denominators. H9 cannot recover missing proposals, a missing nomination, or an H8a `none` result. Do not change the proposal pool, selected-mask geometry, H8 prompts, or H8a outputs.

Freeze two new prompts, schema versions, image presentation, and serialization before dispatch. Stage one must be invariant to target text and prior outputs. Stage two must not receive pixels again: it compares the blind factual record to the target, avoiding a fresh target-conditioned visual selection. Preserve both raw structured outputs and the exact request hashes. No retries, prompt repair, fallback, per-case tuning, or threshold search.

## Evaluation and stop gate

The primary outcome remains the frozen whole-object same-mask criterion: same-instance reference IoU at least 0.50 **and** reference coverage at least 0.90, evaluated on the identical selected mask. Compare candidate-union availability, H8a selected-mask availability, H9 match admission, and final same-mask success separately. The positive denominator remains all nine H8a positive cases; absent H8a masks count as failures, not exclusions. Negatives remain all three fixed H8a negatives; no output is an abstention, while a retained mask that fails truth is a false output. Report every row and stage, errors, hashes, and charges.

This is a conservative continuation test: H9 must retain at least the existing 7/9 positive same-mask successes and return zero false outputs among all three negatives. Do not lower the positive count to gain negative rejection, and do not promote or relax the gate if either requirement fails. At 7/9 on this small fixed pilot, any result is diagnostic rather than qualification. If H9 passes, it only supports a separately reviewed next validation; it does not establish broad accuracy. If it fails, preserve the result and stop this line rather than tuning on the same twelve cases.

This experiment may not help if the target-blind description itself misidentifies the highlighted object, if the facts omit a visually important target relation, or if the second stage maps generic facts to the requested target through language priors. Since stage two sees only text, it cannot correct a visual-description error by looking again. The pilot also has only three negatives, so it cannot establish a dependable false-positive rate. A neutralized-region test is not a universal veto: if another valid instance of the target remains visible after removing one candidate, unchanged presence does not prove that the selected candidate is wrong.
