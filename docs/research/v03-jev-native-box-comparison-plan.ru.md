# План сравнения native Box (Jev) с H8a (перспективное плечо, без результатов)

## Статус и гипотеза

**Статус:** перспективное плечо **подготовлено** в режиме без сети (код и контракт); **ноль** физических вызовов провайдера; **нет** результатов с реального прогона, метрик качества и переноса в продукт. В этом репозитории **не** выполняются платные вызовы, **не** запускается реальный провайдер и **не** фиксируются итоги, достаточные для переноса.

**Гипотеза (до любого прогона):** один прямой native-запрос **Box + Noul** на подготовленном **полном** кадре может дать рамку объекта, **сопоставимую** с H8a, **без** отбора кандидатов, как в плече H8. Это **не доказано** — только проверяемое сравнение **для бенчмарка**; **готовых выводов о качестве нет**, **в публичный API ничего не переносим** и **не** следует заранее ожидать исход по производительности.

Формирование запроса и подготовка (**prepare**) **не** читают эталонную разметку оценщика (`pilot-truth.json` и аналоги). В запрос попадает **исходное** описание объекта (`locate.target`) из **закреплённых** манифестов входных задач — **никогда** эталонная разметка, доступная **только** оценщику.

## Зачем отдельное плечо

H8a — выбранное направление разработки, но порог переноса в продукт не пройден. Отдельное **замороженное** плечо сравнивает **один** структурированный запрос `decisions` с **историческим вариантом сравнения** H8a на **том же** наборе DEV12 (`pilot-v03-{photo,ui,map}-01..04`) через **независимый оценщик** после явного **платного** прогона Jev с провайдером (такой прогон **не** входит в текущую offline-подготовку).

**Ограничение сопоставления:** H8a и Jev-native выполнялись **в разные даты**; это **не** парное доказательство задержки или стоимости на одном физическом прогоне — **задержку и стоимость здесь не сравниваем**.

| Входные манифесты (prepare)   | `benchmarks/v03/pilot-inputs/{photo,ui,map}.json` + неизменяемые SHA-локи; байты изображений под **переданными исходными данными** (`--data-root`)                                                                                                                                              |
| Состояние запроса (`state`)   | Ровно **одно** вхождение **исходного описания объекта**; **общие** (фиксированные) инструкции Noul и Box (**без** повтора target в `questions`)                                                                                                                                                 |

| Снимок возможностей (offline) | SHA-256 `e95ee387c4bb60e207c04553675cccf44bdacce35d75d3dfbb7de9eefa7f2705` (receipt + source)                                                                                                                                                                                                   |
| H8a для оценщика (baseline)   | SHA прогона/оценки из **замороженных свидетельств**; **исторический вариант сравнения** **7/9** успешных рамок на положительных, **2/3** ложных срабатываний на отрицательных — **пересчитывается** оценщиком по бинарным маскам и байтам, **не** принимается из одного **сводного файла JSON** |

## Бюджет, физические вызовы и лимиты

| Параметр                             | Значение                                                                                                                                                                                              |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Число задач                          | ≤ **12** физических HTTP-вызовов (`fetch`), **последовательно**                                                                                                                                       |
| Предварительное допущение (до fetch) | Резерв слота/бюджета и запись `physical-admission-*.json` — **не** физический вызов; учитываются только фактические `fetch`, тело ответа (**response-body**), receipt и **завершение учёта** (settle) |
| Отмена до fetch                      | Если резерв отменён **до** `fetch` — **ноль** физических вызовов и **ноль** учтённой стоимости                                                                                                        |
| Бюджет                               | Резервируемая сумма **≤ 0,25 USD**; **0,02 USD** на вызов с **неизвестной** стоимостью до settle                                                                                                      |
| Дедлайн                              | **240 s** абсолютный на кейс (prepare/пересборка + admission + fetch + read + settle)                                                                                                                 |
| Размеры                              | Тело запроса **≤ 24 MiB**, ответ **≤ 1 MiB**, **закодированный исходник** **≤ 16 MiB**, **подготовленные стороны** **280..1568**                                                                      |
| Ошибки                               | **Без retry**; **2 подряд** ошибки транспорта/протокола/схемы → блок дальнейших **допусков** (admission)                                                                                              |
| CLI                                  | `--allow-paid --freeze --freeze-sha256 --data-root --output`; ключ явно (`credentials.ts` / `--env-file`)                                                                                             |

## Подготовка, выполнение, оценка

**Подготовка (`prepare`, offline, без провайдера):** **полный список исходных файлов с их связями и SHA-256**; **проверка возможностей**; 12 JSON **полезных нагрузок** запроса (без заголовков авторизации); **digest freeze**. Эталонная разметка (**truth**) **не** участвует.

**Выполнение (`execute`, на стороне вызывающего):** повторная проверка **закреплённого списка исходных файлов**, payload и байт source; артефакты request/response/receipt с **однократной записью без перезаписи** на каждый **фактический** физический admission (после реального `fetch`).

**Оценка (`evaluate`, только после прогона с провайдером):** Zod-проверка run manifest; соединение строк run по `caseId` с freeze, **трём закреплённым** манифестам входных задач и **truth только у оценщика** (включая `sourceCaseId`, **число задач по группе** (stratum), SHA/размеры). Эталонная разметка подключается **только после** того, как **producer** завершил прогон; маски H8 **загружаются и хешируются независимо** от формирования запроса. На положительных — сравнение **native Box** (геометрия рамки, **не** маска) с **одним** эталонным **экземпляром** (**instance**) на **той же** instance: IoU рамки **≥ 0,5** и **покрытие** **≥ 0,9** относительно **того же** размеченного объекта; для bird — **единственная** истинная пиксельная маска (тот же reference, что в сопоставлении методов). Бинарные маски H8a и **рамка, вычисленная по бинарной маске**, берутся из замороженного прогона (audit по `selected_mask_path` под каталогом прогона) плюс файл truth **только** у оценщика. На каждый **`resolved`** физический receipt — HTTP 2xx, хеш тела, согласованность model/provider с маршрутом; на разбираемый envelope — согласованность стоимости receipt и `usage.cost` (оба `null` или оба известны и равны в пределах допуска). Поля `confidence` могут быть `null` и **не** участвуют в порогах.

**Статус завершения оценки (как в коде):**

| Условие                                                       | `status`                              |
| ------------------------------------------------------------- | ------------------------------------- |
| Run manifest **`complete`** и все **12** строк **`resolved`** | **`complete`**                        |
| Run **`blocked`** или неполный набор **`resolved`**           | **`partial`**                         |
| Run **`failed`**                                              | оценка **отклоняется** (не evaluable) |

**Сводка отрицательных исходов:** знаменатель **3**; категории `present-false-output`, `absent-correct`, `uncertain`, `error-or-no-call` (аналоги по stratum). **Результатов и переноса в продукт нет**, пока не выполнен отдельный прогон с провайдером (в этой волне прогона **нет**).

## Ограничения и визуализация

- **Noul:** `>0,5` → present, `<0,5` → absent, `=0,5` → uncertain; `confidence` **не** входит в порог (**решение о наличии** отдельно от Box).
- **Box:** `confidence` **не** входит в порог; Box **не** выражает **значимое отсутствие** через геометрию (см. TypeSafe Box).
- **Prepare:** один полный кадр; без crops/grids/отбора кандидатов/OCR.
- **Отчёт (PNG + `comparison.html`):** пишется оценщиком **после** явно переданного **прогона с реальным провайдером** — голубая заливка: **фактические** **пиксели переднего плана** бинарной маски H8a (0/255); синий контур: **рамка по той же маске**; красный: **native Box** Jev (рамка). В этой волне — только offline-подготовка, **без** прогона и **без** готовых метрик.

**Скрипты:** `benchmarks/v03/run-jev-native-box.ts` (prepare/execute), `benchmarks/v03/evaluate-jev-native-box.ts` (evaluate).
