[Set-of-Mark](https://arxiv.org/abs/2310.11441) supplies the rationale for visual references tied to real image regions. Its results motivate the first branch, but do not establish a gain for our models or maps. [POPE](https://arxiv.org/abs/2305.10355) documents object hallucination and sensitivity to visual instructions; it motivates explicit negative evaluation, not a claim that a binary question eliminates hallucinations.

The official [SAM 3 agent design](https://github.com/facebookresearch/sam3/blob/main/sam3/agent/system_prompts/system_prompt.txt) separates simple concept segmentation from selecting the instance referred to by a more complex query. This supports testing a separation of concerns. It does not justify importing that agent's permissive reinterpretation of user requests or its open-ended retry loop: our authored target, bounded calls and independently verified negatives remain fixed. No code or prompt text from that file is incorporated here.

## Alternative assets: assess before implementation

[Florence-2-base's official model card](https://huggingface.co/microsoft/Florence-2-base) lists phrase grounding, detection and segmentation tasks under MIT terms. It is a possible separate proposal experiment if availability is the limiting stage. Before use, pin the checkpoint, implementation and license, review any custom loading code, test source-coordinate transforms, and keep inference in an owned bounded process. A generative region proposal is not a confirmed mask: only validated source-sized foreground from the explicitly supplied segmenter may produce an extraction. It has not been downloaded or tested in this iteration.

[SAM 3](https://github.com/facebookresearch/sam3) supports text and exemplar conditioned segmentation; its official setup requires a newer Torch/CUDA environment than the current SAM 2 probe. Its [checkpoint page](https://huggingface.co/facebook/sam3) also requires authenticated access and acceptance of its conditions. It is therefore not an immediate dependency or a replacement in the MIT package. Do not bypass access controls, silently upgrade the current research environment, bundle weights, or infer permission to share account details. Existing caller-supplied ports remain independent of any such future adapter.

For any selected branch, first write a concrete implementation plan with the exact transform/prompt, inputs, resource limits, regression cases and fixed comparison. Then run one bounded pilot. Do not repeatedly adjust a threshold against the same failures, swap source labels, or replace the selected candidate with the evaluator's best mask. A successful pilot still requires full development comparison and independent qualification.
