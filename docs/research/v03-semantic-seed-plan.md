# H2c: end-to-end semantic seed-mask selection

Written before implementation and dispatch. H2b, a five-case exposed mechanism probe, improved mean mask IoU from 0.6350 to 0.9133 by selecting among four existing seed-point masks with one Luna Choice. It did not prove end-to-end improvement. Its overlay label obscured some top-edge pixels in one source; retain that failed presentation detail and correct it prospectively.

The next candidate keeps the original presence classifier and region search. A caller-configured MobileSAM proposal adapter runs one encoder and one center-point decoder, returns all four masks, and closes its native job. A benchmark-only SegmentationPort wrapper presents the original plus four full-context mask overlays to the explicitly injected DecisionPort. One closed A–D/none Choice selects a mask. Native quality scores, case IDs and truth never enter that request. The wrapper validates source geometry, packed bytes, foreground, hard ROI and seed intersection. `none` and invalid grounding yield unknown, never a rectangle stretched to look complete.

The wrapper returns actual mask pixels to the existing extraction workflow. Its existing separate box-containment check remains enabled. No enclosing-mask correction is attempted by this candidate: it has no `expand` method. This is an explicit recipe difference from v0.2, whose point mask and single optional expansion remain the paired baseline. Maximum six physical calls per case for either recipe, one native job, serial cases, one absolute 120-second deadline, no retry/fallback. A 12-case paired DEV screen uses at most 144 calls, two independent 72-call/$4 conservative ledgers, and reports total known/unknown exposure. It is not qualification.

Labels appear in a new 42px margin outside the source. No source pixels are removed or overwritten by the label. Record the display padding/scale; mask geometry remains in original source coordinates. The source image is independently shown without overlay. Cyans are presentation annotations only, never a segmentation heuristic.

Implement benchmark composition and native explicit `seed-center` sampling first. Preserve old native sampling default, all public model/provider injection, region behavior, and native ownership. Do not expose the new composition as a supported public algorithm before the fixed DEV comparison and independent qualification. Regression checks cover edge targets, raw-score tie semantics, prompt privacy, foreign/out-of-ROI masks, physical cancellation and caller-owned proposal lifetime.

H1's independent paired seed screen has now completed: baseline 5/9 positive hits and 0/3 negative false regions; zoom 4/9 and 1/3. Reject H1 for promotion. Its 88 physical calls cost $0.049428, with no unknown charges. Do not add zoom to H2c or tune it on these results.
