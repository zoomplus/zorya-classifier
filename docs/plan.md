# Accepted open-source extraction plan

Current implementation: [accepted 0.2 plan](0.2.0-plan.md), whole-object bounds, extraction and comparative text-only image experiments. The first-release plan below is retained as history.

First deliver an independent MIT Node.js/TypeScript library with classify(text/image/both) and locate(image,target), powered by Jev 1.14/TypeSafe. Preserve three Choice stages for localization, stable maxima/ties and source coordinates; no implicit model/provider fallback or retries. Classification is one native Choice. Separate heavy optional refinement and game/application dependencies.

Prepare public contracts, strict schemas, source rules, architecture/API/operations documentation, examples/CLI, offline regressions and Windows/Linux CI. Package into a clean npm archive and test installation outside the repository. Scan release contents for secrets, private paths and unwanted assets. Prepare a clean source repository; public GitHub/npm publishing is a separate action.

Evaluate 60 licensed real photographs (20 development/40 heldout) and 30 authored text fixtures (10/20). Separate raw producer inputs from ground truth. Compare classification against an independently called identical native Choice; evaluate one/two-stage locator prefix ablations from the three-stage run. Record mistakes, errors, latency, costs, true unknowns and visual overlays. No universal superiority claim without evidence.

Acceptance requires executed source checks, clean independent consumer install, an honest real-provider report and complete release documentation. Configured CI is not evidence of execution. Historical gaming/microphone checks and installer work remain separate.

## Owner revision: universal vision classification before first npm publication

The owner replaced the Jev-centered release design after initial GitHub creation and before npm publication. Ordinary image-capable language models must work without a native classification/Decisions API. Implement an OpenRouter chat-completions adapter that requests closed ranked IDs and explicit present/absent/unknown predicates, validates all outputs and rejects invented IDs, extra questions, truncation, refusals and malformed JSON. Do not manufacture probabilities from ranks. Keep the original native adapter only as an optional compatibility/benchmark integration, never an implicit dependency/fallback.

Preserve the three grid stages, source-pixel geometry, input ownership, bounded queues, cancellation, byte caps, no retries/model fallback and route accountability. Extend the internal/public result contract with explicit rank-only evidence. The selected class is the first ranked ID; only genuine provider probability distributions remain probability-valued. Update examples, CLI, docs and rules to the generic adapter.

Compare cheap general vision candidates under a newly authorized bounded paid run before recommending the cheapest tested route that meets the recorded baseline. Preserve historical Jev reports as historical evidence, not a qualification for a different backend. A pending separate paid-run request does not authorize dispatch until approved. npm publication waits for updated code, independent archive checks, Windows/Linux CI and honest current-model evidence.

The first hosted Windows CI exposed a temporary-directory alias problem in the declaration-isolation check. Resolve Windows 8.3 aliases with the native filesystem canonicalizer; do not broaden allowed declaration roots or skip archive verification. Preserve the failed run and verify the corrected check in hosted Windows CI.

Additional owner requirement: provide a direct OpenAI-compatible endpoint adapter (including anonymous local servers/custom authentication) and a public custom port. OpenRouter is optional. README must explicitly distinguish configurable vision-model support from models/routes actually tested, with per-model accuracy, error, latency and price data.

## Latest owner priority: native decision models except Jev

Prioritize Luna Decisions through the typed Decisions API. Keep model/provider explicit and implement a generic native adapter; retain ordinary vision-chat support as an alternative, and Jev only as an optional historical integration. Do not silently fall back between protocols. Native probabilities remain genuine values; quantization assumptions require explicit model-specific evidence/configuration. Reallocate the remaining approved comparison budget without exceeding290 total calls/$0.50. Current ordinary runs and their failures remain preserved.
