# Acceptance: standalone library

This acceptance concerns the extracted MIT Node.js library, not the Zorya desktop application, installer, microphone or game session. The caller supplies a `DecisionPort` or explicitly configures an adapter; model/provider recipes below are examples, not library defaults. Ordinary vision chat, direct OpenAI-compatible servers and native decisions are all supported. Jev is optional historical compatibility.

## Current gate state

The latest integrated source snapshot, `35e3064`, passed 393 Linux offline tests, formatting, source checks and the installed-archive consumer. Its additions are benchmark-only caller composition and independent routing/lifecycle tests; the runtime bytes are unchanged. Hosted CI for `be275a6` passed all four Windows/Linux × Node 22/24 jobs. The later [35e3064 run](evidence/v02/ci-35e3064.json) passed both Linux jobs but failed a new benchmark CLI test on Windows because its assertion assumed POSIX path separators. The assertion repair uses the platform path resolver; its fresh CI remains required. The [installed-archive snapshot](evidence/v02/integration-35e3064.json) identifies its exact scope.

All 53 runtime source files remain byte-identical to `0c365cb`, as do the 106 compiled runtime files. The first proposal resource run completed its configured wall-clock phases, but its observed process lifetime and summed monotonic operation durations did not prove the required physical duration. It is retained as historical evidence. Replacement harness `261dc23` uses monotonic phase deadlines, enforces the full duration minima, and has a separate kernel-uptime observer. Its fresh two-hour run is in progress.

The [first frozen blind candidate](evidence/v02/heldout-evaluation-20261020.md) failed: 3/60 positive whole-object boxes matched, there were 2/20 false locations against a limit of one, and the paired photo bootstrap interval was [0, 0.20], whose lower bound must be positive. The no-image control completed all 40 photos with no successful location. No alternative is selected from these revealed heldout results.

The next development experiment composes caller-supplied ports: spatial Choice questions and independent binary-presence questions use explicitly configured adapters. It changes no model defaults or runtime source. It must pass the original DEV40 criteria and a fresh, independently frozen heldout cohort before qualification. Model/provider choices remain benchmark configuration owned by the caller.

## Quality limits

Luna Decisions matches the historical Jev photo/text counts on this corpus; this is not proof of statistical non-inferiority, calibration or universal superiority. Two disjoint native sessions cover the full90 classification cases without replay or prompt changes. Public photographs may overlap training; text cases are authored fixtures, not customer traffic. No independent annotation/duplicate audit was performed.

Localization is experimental. The first native smoke failed at its195-option/nine-image fine request; an explicit replay returned HTTP502 with provider refusal. The original error and diagnostic remain preserved. A separate fixed flower-image smoke completed all three native stages in4.75s; its reviewed receipt is in docs/evidence, and it does not replace a full localization evaluation. A selected cell is not segmentation, an exact object center, tracking or a universal map/minimap guarantee. Offline fixtures are not real-model quality evidence.

Paid comparison accounting is separate from the historical337-call Jev work. The owner expanded the comparison limit to1000 calls while retaining the$0.50 ceiling. Reported costs are reconciled only from retained numeric receipts; failed classifications remain failures, unknown charges retain conservative reservations. Local admission accounting is not a provider-side account cap or a verified invoice. The comparison finished at332 calls, known cost$0.03456876 and four unknown costs; conservative accounted exposure is$0.23456876. Exact receipts are in the model evidence/release manifest.
