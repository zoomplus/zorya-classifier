# Categorical-presence DEV6 pilot

This benchmark-only profile tests a caller-owned split of decision questions. The Sol route answers classification and spatial interval Choice requests. Each binary whole-object-presence question is converted into one closed native Choice question (`present`, `absent`, `unknown`) and sent to the pinned Luna Decisions route. The conversion preserves the original question ID, proposition, state, and image parts. It selects the answer with the library's validated maximum and stable input-order tie rule, then returns a categorical presence answer without fabricating probabilities. The native route recorder wraps the converted port, so its immutable logical trace, wire body hash, and receipts describe the actual Choice request.

The profile uses six exposed photo DEV inputs: `photo-dev-present-01`, `photo-dev-present-02`, and `photo-dev-absent-01` through `photo-dev-absent-04`, from input manifest SHA256 `6c9ed29d8586c7887ae0861fc853baf203cb43790df4959390da4b5cc9ac679a`. It retains the existing 8-pixel box tolerance, three extent passes, and public classifier extraction flow with pinned MobileSAM assets. Each operation has one 120-second deadline; two cases may be active concurrently. The run budget is at most 100 actual fetch admissions, $5, and a $0.05 reserve per unknown-cost call. It makes no automatic retries or route fallback. Timings are unranked while this development screen is concurrent with other development work.

The script requires an explicit `--dry-run` or `--allow-paid` mode. Paid dispatch reads only the environment variable named by `--api-key-env`, defaulting to `OPENROUTER_API_KEY`; it never reads a credential file or writes the value into artifacts. The offline preflight verifies all six pinned images and admits zero provider calls. Paid execution requires explicit encoder and decoder paths.

This six-case screen is an exposed development experiment, not release qualification. It does not change the library's model-selection behavior or public defaults. Ground truth is never loaded by the producer.
