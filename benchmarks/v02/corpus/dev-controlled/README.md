# Controlled map and UI supplements

These 20 development cases are a controlled supplement: 7 icon cases plus 3 explicit absences from Geany, and 7 generated-map cases plus 3 explicit absences from Freeciv. The heldout supplement has 15 icon cases plus 5 explicit absences from AbiWord and 15 generated-map cases plus 5 explicit absences from OpenTTD. Each application/game family is confined to one split. The heldout input manifest, truth, and source ledger are local-only under ignored `benchmarks/cache/v02/corpus/controlled/heldout-controlled/` and are not tracked.

These are screenshots of real, licensed applications and game renderers running in isolated Xvfb sessions, with authored text/code or locally generated deterministic maps. They are not natural user captures. The map/game and app-family diversity is one group per split/stratum, so this is a feasibility supplement and does not satisfy the plan's natural-source acquisition or independence requirements. The freeciv map exposes only a small explored area; OpenTTD is a single generated seed. Do not report these results as natural UI/map accuracy or as qualifying the complete corpus gate.

Input manifests contain only image path/hash/dimensions, target prompt and closed class options. Ground truth and source/license ledger are separate files. Boxes were prepared with model-assisted visual review of the actual pixels, not by a human annotator or the candidate algorithm. They identify visible toolbar glyphs, map-tile extents, and town-name text extents; there are no masks. The common Openbox window frame and system theme are capture-harness context only and are never annotated; shared window-manager controls are excluded. Negative classes were checked against the complete capture, not inferred from missing annotations. Treat both the annotation method and the controlled scene design as quality limits.

All images are 1280×900 PNGs stored under ignored `benchmarks/cache/v02/corpus/controlled/`. The source ledger records package versions and hashes of installed copyright metadata. The UI text/code files were authored for this task. Freeciv's local generated scene used its packaged GPL-2+ game data. OpenTTD used seed 20261020 and the separately packaged OpenGFX 7.1 GPL-2 assets with sound/music disabled. No raw upstream dataset or game asset files are included in the repository.
