# Region-seeded full-frame extraction profile

`native-luna-region-seeded-sam-dev-v1` is a separately named benchmark recipe for the original exposed 40-case DEV set (20 photo, 10 independent UI, 10 independent map, including negatives). It runs the unchanged three-choice region locator, then makes one caller-owned CPU MobileSAM `seed-region` pass over the full oriented source image. The seed cell is recorded before inference and remains distinct from the box and center derived from foreground mask pixels. There is no whole-object extent search, same-instance confirmation request, completeness request, OCR, or box inferred from the seed cell.

The explicit benchmark route is `openai/gpt-6-luna-decisions` through OpenAI's Decisions endpoint. The library itself remains model-free and callers still own the ports. One classification request and at most three region-search requests are allowed per case, plus one local native segmentation call. The case deadline is 120 seconds, two cases may run concurrently, and the shared MobileSAM pool uses one active child with two waiters and two threads. The profile has a 250-fetch, $5, $0.05-per-unknown-cost hard budget. It has no automatic retry or provider fallback. Timing is not ranked.

`native-luna-presence-first-region-seeded-sam-dev-v2` and `native-luna-presence-first-region-no-image-control-dev-v2` are separate DEV profiles. The corresponding HELDOUT identities are `native-luna-presence-first-region-seeded-sam-heldout-v2` and `native-luna-presence-first-region-no-image-control-heldout-v2`; they use the same caller-side policy and require an external strict freeze whose authorization explicitly sets `requireClassifiedPresence: true`. The profile and phase must match the authorization, as must the phase budget (DEV 250 fetches/$5; HELDOUT 600/$10). The v2 profiles preserve the same classification and region prompts as v1, but reuse the case's already recorded classification result as a caller-side gate: only a successful `present` classification starts region search; absent classifications are recorded as extraction `not-found` with reason `classification-absent`, and failed classifications remain `failed` with reason `classification-failed`. They do not issue a second classification request, change the public classifier, alter the locator or segmentation prompt, or select a different model. The v1 and historical artifacts remain unchanged. HELDOUT dispatch still requires a separate external GO; this code support alone is not authorization to run it.

Each recorder exposes typed persistence failures. If a logical request or physical receipt cannot be persisted, the run aborts at the next stage boundary, cancels sibling cases, joins all workers, and preserves an incomplete summary. Ordinary provider errors remain failed case outcomes and do not by themselves stop the profile.

The separately named v3 profiles, `native-luna-presence-first-checked-region-sam-dev-v3` and `native-luna-presence-first-region-no-image-control-dev-v3`, keep the same classification gate, region search, full-source seed-region SAM call, task prompts, route, deadline, concurrency, and DEV input manifests. The candidate additionally asks up to two closed questions about whether the actual mask-derived box encloses the seeded visible instance. If the first answer requests expansion, the existing caller-owned SAM adapter may provide one actual enclosing mask, followed by the second and final check. The flow does not add an extent search or invent coordinates. Its per-case limit is six model fetches total (one classification, up to three region-search requests, and up to two box checks); the candidate extraction stage is capped at five. The paired no-image profile has zero box checks and no segmenter, while retaining a four-fetch per-case limit. Both profiles retain the phase budgets, 120-second deadline, two case workers, one active native child plus two waiters, two native threads, and zero retries/fallbacks. Each case records ordered check attempts with request hashes and physical-call IDs separately from the original region-search seed record. These are research-only profiles; the public classifier's defaults and model-free caller-owned ports do not change.

`native-luna-region-no-image-control-dev-v1` is a paired control. It uses the same question, target, route, and region-task policy but removes image parts at the caller's decision-port boundary and asserts their absence again at the fetch boundary, including rejecting data-image/base64 markers in strings. Deterministic raster normalization and grid construction still run locally to preserve identical geometry text; the generated image parts are discarded before the model adapter and cannot produce coordinates or semantic answers. The control performs no segmentation, OCR, or semantic computer vision. The ordinary raster presentation may still be constructed locally for matched geometry, but no image parts reach the model. It records only the region locator's seed; it emits no mask-derived object box. Candidate mask and box results therefore remain candidate-only outcomes, while paired localization compares the seed region.

Run an offline preflight with:

```sh
PATH=/root/.nvm/versions/node/v24.12.0/bin:$PATH node --import tsx benchmarks/v02/run-region-seeded-dev.ts --dry-run
```

The paid command requires an explicit `--allow-paid`, and output stays under `.run/v02/region-seeded`. Heldout mode requires an external strict freeze and three explicit input-manifest paths and hashes; it uses the same recipe code with the heldout 80-case groups and 600-fetch/$10 caps. The producer never loads evaluator truth, source ledgers, or private image paths into provider prompts or output manifests.

The new DEV profile is selected explicitly, for example:

```sh
PATH=/root/.nvm/versions/node/v24.12.0/bin:$PATH node --import tsx benchmarks/v02/run-region-seeded-dev.ts --dry-run --presence-first
PATH=/root/.nvm/versions/node/v24.12.0/bin:$PATH node --import tsx benchmarks/v02/run-region-seeded-dev.ts --dry-run --variant no-image-control --presence-first
PATH=/root/.nvm/versions/node/v24.12.0/bin:$PATH node --import tsx benchmarks/v02/run-region-seeded-dev.ts --dry-run --checked-region
PATH=/root/.nvm/versions/node/v24.12.0/bin:$PATH node --import tsx benchmarks/v02/run-region-seeded-dev.ts --dry-run --variant no-image-control --checked-region
```
