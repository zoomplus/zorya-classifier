# История изменений

## 0.2.0

- Добавлен явный HTTP-режим с IP allowlist для клиентов, которые не передают собственные HTTP-заголовки аутентификации.
- Добавлены краткоживущие session capabilities, изоляция заданий и артефактов по сессии, а также ограниченные лимиты запросов и заданий.
- Сохранены OIDC, stdio и бизнес-семантика исходных шести инструментов.
- Пакет продолжает использовать опубликованную библиотеку `zorya-classifier@0.2.3`.
